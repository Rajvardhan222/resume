A simple text Editor that uses DOM API and text area and uses the concept of WUCIWUG(what you see is what you get). This whole thing is build around textarea which is native html and we hide its output and show the out custom value. Do have a look at it, It is not a replacement for your code editor but a fun project that though me dom api has so much power.
